## 🚀 INSTALLATION STEPS

### Step 1: Install WordPress

If you don't have WordPress installed yet:

1. Download WordPress: https://wordpress.org/download/
2. Install on your server (5-minute installation)
3. Log in to WordPress admin panel

### Step 2: Install the Theme

**Method A: Upload ZIP (Easiest)**

1. Create a ZIP of the theme:
   ```bash
   cd wordpress-theme
   zip -r opensourcebox-v2.0.zip opensourcebox/
   ```

2. In WordPress Admin:
   - Go to **Appearance > Themes**
   - Click **Add New** > **Upload Theme**
   - Choose `opensourcebox-v2.0.zip`
   - Click **Install Now**
   - Click **Activate**

**Method B: FTP/SFTP Upload**

1. Upload the `opensourcebox` folder to:
   ```
   /wp-content/themes/opensourcebox/
   ```

2. In WordPress Admin:
   - Go to **Appearance > Themes**
   - Find "OpenSourceBox"
   - Click **Activate**

### Step 3: Import Your Content

1. In WordPress Admin:
   - Go to **Tools > Import**
   - Click **WordPress**
   - Install importer (if needed)
   - Click **Run Importer**

2. Upload `wordpress-import.xml`

3. Assign authors or create new ones

4. Check ✅ "Download and import file attachments"

5. Click **Submit**

6. Wait for import (143 posts)

### Step 4: Configure Theme

1. **Set Permalinks**:
   - Go to **Settings > Permalinks**
   - Select "Post name"
   - Click **Save Changes**

2. **Create Menus**:
   - Go to **Appearance > Menus**
   - Create "Primary Menu"
   - Assign to "Primary Menu" location

3. **Add Widgets**:
   - Go to **Appearance > Widgets**
   - Add widgets to Sidebar and Footer areas

4. **Customize**:
   - Go to **Appearance > Customize**
   - Upload logo
   - Set footer text
   - Adjust colors (optional)
