README.md              - Theme documentation and installation instructions

search.php             - Search results template

Installation:
------------
1. Copy the 'opensourcebox' folder to /wp-content/themes/
2. Activate via Appearance > Themes in WordPress admin
3. Configure menus and widgets
4. Customize via Appearance > Customize

For detailed migration instructions, see MIGRATION_GUIDE.md
